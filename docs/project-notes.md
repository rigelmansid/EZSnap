## 项目概况

- 是什么：截图并标注的 macOS 菜单栏小工具，Swift + AppKit，不依赖第三方库。用法、构建和代码结构见 [README](../README.md)。
- 给谁用：发给别人用（D-3）。
- 目标：方便快速截图，并标注。
- 不做什么：长截图、OCR、截图录屏、开机自启。跨屏选区和自定义快捷键要做，见待办。

## 待办

- [ ] 在真实应用里验证 2026-10-20 的两轮修复（D-2、D-4）：授权屏幕录制之前，先在权限提示框开着时多按几次快捷键，关掉后不应再弹；授权后试文字框里 ⌘V 粘贴；多屏时一块屏上正在输入文字、点另一块屏后继续打字和按 Esc；鼠标从主屏移到另一块屏后，主屏不应留着整屏蓝框，Shift 能切换颜色格式；⌘Z 撤销最后一个标注后光标马上变成手形
- [x] 补全项目概况：给谁用、目标、哪些明确不做（D-3）
- [ ] 跨屏选区（D-3）：现在每块屏各管各的选区，一块屏有选区时锁定其他屏（OverlayView.locked），要先改这个模型
- [ ] 自定义快捷键（D-3）：现在只能从 3 个预设里选；按用户实际按下的键位录制，下面 AZERTY 那条也一起解决
