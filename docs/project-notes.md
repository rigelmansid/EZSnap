## 项目概况

- 是什么：截图并标注的 macOS 菜单栏小工具，Swift + AppKit，不依赖第三方库。用法、构建和代码结构见 [README](../README.md)。
- 给谁用：发给别人用（D-3）。
- 目标：方便快速截图，并标注。
- 不做什么：长截图、OCR、截图录屏、开机自启。跨屏选区和自定义快捷键要做，见待办。
- 仓库：GitHub 私有仓库，地址见 private-notes.md（D-7）。
